# 🚀 Personal Portfolio & Data Analytics Hub

Este es mi portafolio profesional desarrollado con **Django**. No es solo una vitrina de proyectos, sino una plataforma que integra visualizaciones de datos complejas, como análisis de rendimiento deportivo en tiempo real.

## 🌟 Características Principales

* **Carrusel Moderno**: Implementación de un slider de pantalla completa utilizando **Tailwind CSS** y JavaScript, optimizado para evitar colapsos visuales y ofrecer transiciones fluidas.
* **QuantumBug Studio**: Proyecto destacado de página web de un estudio de videojuegos y simuladores, realizado con **Laravel** y **React** enfocado en el FrontEnd con  **Tailwind CSS**.
* **NBA Shot Chart Analytics**: Proyecto destacado que utiliza la `nba_api` para procesar coordenadas de tiro. Incluye un sistema de visualización híbrida (frecuencia y eficiencia) mediante **Matplotlib** y **NumPy**.
* **Arquitectura Dinámica**: El contenido se gestiona desde el panel de administración de Django, permitiendo añadir snippets de código y enlaces a GitHub de forma dinámica.
* **Modo Oscuro/Claro**: Persistencia de tema mediante `localStorage` y Tailwind CSS.

## 🛠️ Stack Tecnológico

* **Backend**: Python 3.10+, Django 4.x, Laravel.
* **Frontend**: Tailwind CSS (vía CDN), JavaScript (ES6+), FontAwesome, React.
* **Análisis de Datos**: Pandas, NumPy, Matplotlib, NBA_API.
* **Base de Datos**: SQLite (Desarrollo) / PostgreSQL (Producción).
